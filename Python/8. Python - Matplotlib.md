#### Import Matplotlib library
```python
import matplotlib.pyplot as plt

# here 'plt' can be set for a shortcut use and you can give anything you want
```

#### Figure Setup & Display
```python
plt.figure()             # creates a new canvas for chart.

plt.plot()               # creates lines

# Titles & Labels
plt.title("title_name")  # adds a main title to the top of the plot.
plt.xlabel("lable_name") # adds a label for the horizontal x-axis.
plt.ylabel("lable_name") # adds a label for the vertical y-axis.

# Enhancements
plt.grid(True)           # draws a background grid lines.
plt.legend()             # sets a label for each line.
plt.tight_layout()       # automatically adjusts padding so labels and titles don't get cut off.

plt.show()               # displays the plot on screen.
```
