
#### Types of Plots
- there are 5 types of plots - Line Plot, Bar Plot, Scatter Plot, Pie Chart, Histogram
![[plot_types.jpg]]

#### Import Matplotlib library
```python
import matplotlib.pyplot as plt

# here 'plt' can be set for a shortcut use and you can give anything you want
```
#### Create Canvas for Chart
```python
plt.figure()             # creates a new canvas for chart.
```
#### Create lines and their labels
```python
plt.plot()               # creates lines
plt.legend()             # sets a label for each line.
```
#### Titles & Labels
```python
plt.title("title_name")  # adds a main title to the top of the plot.
plt.xlabel("lable_name") # adds a label for the horizontal x-axis.
plt.ylabel("lable_name") # adds a label for the vertical y-axis.
```
### Extra Enhancements
```python
plt.grid(True)           # draws a background grid lines.
plt.tight_layout()       # Auto-adjusts padding so labels/titles aren't cut off
plt.xlim(0, 100)         # Sets the x-axis limits (min, max)
plt.ylim(0, 50)          # Sets the y-axis limits (min, max)
```
#### Show plot
```python
plt.show()                 # displays the plot on screen.
```
#### Save as image
```python
plt.savefig("plot.png", dpi=300) # Saves plot as an image (call BEFORE plt.show())
```
